# Security and data handling

Do not open an issue or pull request containing NSP/NSZ/XCI/NCA files,
`prod.keys`, `title.keys`, title keys, tickets, extracted game files, saves, or
an IPA that embeds the game. Keep those files on the owner-operated machine.

The public code is a build wrapper around the pinned open-source nxnative
dependency. Reports should contain only sanitized logs, stack traces, and
metadata needed to reproduce a compatibility fix.
